# Security policy

## Reporting a vulnerability

Please report security issues privately, never in a public issue:

- **GitHub:** use **Report a vulnerability** on this repository's **Security** tab (private advisory), or
- **Email:** support@bestanswerhub.com with the subject line `SECURITY`.

Include the affected URL or file, steps to reproduce, and the impact you observed. Reports get a first reply within 5 working days. Please allow up to 90 days for a fix before public disclosure.

## Scope

- The website at https://www.bestanswerhub.com and the source in this repository.
- The free browser tools. They run entirely client-side; files you load into them are not uploaded.

Good-faith research that avoids privacy violations, data destruction and service disruption will not be pursued.

## Out of scope

- Denial-of-service and volumetric testing.
- Social engineering, and physical attacks.
- Findings that need a compromised device or browser.
