# Site Architecture & Technical Stack

Best Answer Hub is a static site built with Astro 5.x and Tailwind CSS 3.x. It is deployed as static HTML to Hostinger shared hosting via FTP. There is no server-side runtime, no database, and no API backend. Every tool is implemented as a single HTML page with vanilla JavaScript that executes entirely in the user's browser.

Security model:
- All processing happens client-side using browser APIs: Canvas 2D, Web Crypto API, FileReader API, TextEncoder/TextDecoder
- No data is uploaded, logged, or transmitted to any server
- DOMPurify sanitizes any third-party HTML before DOM insertion
- File size limits prevent memory exhaustion: PDFs/images ≤ 50 MB, JSON imports ≤ 1 MB, text files ≤ 1 MB
- CSP headers in .htaccess enforce strict script and connect source policies

SEO infrastructure:
- Every page includes JSON-LD structured data (WebPage, FAQPage, BreadcrumbList)
- Open Graph and Twitter Card meta tags on every tool page
- Sitemap auto-generated on every build
- datePublished and dateModified Schema.org properties on every page
- 8–14 SEO-optimized FAQs per page, synced between visual HTML and JSON-LD schema
- robots.txt allows all major AI crawlers (GPTBot, ClaudeBot, PerplexityBot, OAI-SearchBot, Google-Extended, Googlebot, Bingbot)
